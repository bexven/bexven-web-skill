# HTML/CSS craft

Load at build steps 3–4. Defaults, not menus. Everything here assumes tokens from `css/tokens.css` (generated by `tokens_to_css.py`).

## 1. Document shell

```html
<!DOCTYPE html>
<html lang="nl">            <!-- the client's language -->
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">  <!-- never maximum-scale / user-scalable=no -->
  <title>…</title>
  <!-- meta, robots, OG, JSON-LD: see seo-local.md -->
  <link rel="preload" href="/fonts/text-var.woff2" as="font" type="font/woff2" crossorigin>
  <link rel="stylesheet" href="/css/tokens.css">
  <link rel="stylesheet" href="/css/styles.css">
  <script src="/js/site.js" defer></script>
</head>
<body>
  <a class="skip-link" href="#main">Skip to content</a>
  <header class="site-header">…<nav aria-label="Main">…</nav></header>
  <main id="main">…</main>
  <footer class="site-footer">…</footer>
</body>
</html>
```

- One `<h1>`; sections start at `<h2>`; no skipped levels. Each `<section>` has `aria-labelledby` pointing to its heading.
- Links are `<a href>`, actions are `<button type="button">`. No clickable divs, no `<a><button>`.
- No duplicate IDs. Brand names get `translate="no"`.
- For the static mock, small CSS (<14KB) may be inlined in `<style>`; otherwise one stylesheet. Never CSS `@import` (tokens are linked, not imported).

## 2. Cascade layers and custom properties

```css
@layer reset, base, layout, components, utilities;
```
- `reset`: box-sizing, margin zero, `img,svg,video{display:block;max-width:100%;height:auto}`, form controls inherit font.
- `base`: element styles from tokens (body, headings, links, `::selection`, focus).
- `layout`: container, section shells, grids.
- `components`: `.btn`, `.nav`, `.field`, `.review`, `.nap`…
- `utilities`: `.visually-hidden`, `.flow`, few others.

Layers kill specificity fights; never use `!important` except in the reduced-motion block and `.visually-hidden`.

Role aliases sit on top of generated tokens, so components read roles, not palette steps:
```css
@layer base {
  :root {
    --ink: var(--color-text);          /* derived dark, never #000/#111 */
    --paper: var(--color-surface);     /* never #fff/#fafafa unless the brand is literally white */
    --accent: var(--color-accent);     /* allowed: primary CTA, links, focus ring */
    --rule: var(--color-border);
    --focus: var(--color-accent);
    --container: 76rem;                /* 1216px; one container for header, sections, footer */
    --gutter: clamp(1rem, 4vw, 2.5rem);
  }
}
```
Component-local properties (e.g. `.btn { --btn-bg: var(--accent); background: var(--btn-bg); }`) make variants a one-line override.

## 3. Fluid type with clamp()

Build each role from a min (at 360px) and max (at 1280px) size. Formula: `clamp(min, calc(min + (max − min) * ((100vw − 22.5rem) / 57.5)), max)`, or the simpler slope form below.

Default scale (ratio ~1.25 for content, one bigger jump for the hero):

| Role | Min → max | Line-height | Tracking |
|---|---|---|---|
| display (hero h1 only) | 2.5rem → 4.5rem (cap 6rem) | 1.0–1.1 | −0.02em |
| headline (h2) | 1.75rem → 2.5rem | 1.15 | −0.01em |
| title (h3) | 1.25rem → 1.5rem | 1.25 | 0 |
| body | 1.0625rem → 1.1875rem (17→19px) | 1.5 | 0 |
| body, older audience | 1.125rem → 1.25rem | 1.55 | 0 |
| small/label | 0.875rem → 0.9375rem | 1.4 | +0.01em |

```css
h1 { font-size: clamp(2.5rem, 1.6rem + 3.9vw, 4.5rem); }
```
- Use `rem + vw` so zoom still scales text. Never pure `vw`.
- Max 3 type sizes above the fold. Reserve the display size for one context.
- Weights: ~400/500/600. 700+ rarely. Nothing under 300. No 100-vs-900 "contrast".
- If DESIGN.md typography has `display-lg` with fontSize 72px, that is the max; pick the min (~55–60% of max) and write the clamp.

## 4. Spacing scale

4px base, named steps (DESIGN.md `spacing` → `--space-*`). Typical: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128.
- Inside a group 8–16px; label to field 6–8px; between groups 24–48px; between sections 64–120px desktop (calm niches high, dense trades low), roughly 60% of that on mobile.
- Bottom padding of a section often ~1.25× top (optical).
- More space above a heading than below it.
- `.flow > * + * { margin-block-start: var(--flow-space, 1em); }` for running text; paragraphs separated by space, not indents too.
- Vary padding by context. One value everywhere is a tell.

## 5. Layout

- Container: `width: min(100% - 2 * var(--gutter), var(--container)); margin-inline: auto;`.
- Grid sizes things; JS never measures layout. Prefer asymmetric splits: `grid-template-columns: 3fr 2fr` or `2fr 1fr`; spans and offsets over equal columns.
- Text containers `max-width: 65ch`. Never edge-to-edge text.
- Flex/grid children that hold text: `min-width: 0`. Emails/URLs: `overflow-wrap: anywhere`. Never truncate prices, dates, names.
- Hero only: `min-height: 100svh` (or less). Hero content may sit top-biased.
- Full-bleed and fixed bars: `padding-inline: max(var(--gutter), env(safe-area-inset-left))`.
- Reflow at 320px with no horizontal scroll; usable at 200% zoom.
- `scroll-padding-top` on `html` = header height, so anchors and focus clear a sticky header.

### Container queries (where useful)
Use them for components that live in different widths (a review or service item in a 2/3 column and in a full row), not as a replacement for page media queries.
```css
.service-list { container-type: inline-size; }
@container (min-width: 40rem) { .service { grid-template-columns: 12rem 1fr; } }
```

## 6. Shape and depth

- One radius language from DESIGN.md (`--radius-*`). Never one mid radius (8–12px) on everything. Do not mix sharp and round in one view.
- Concentric nesting: inner radius = outer radius − padding.
- Elevation: flat + tone by default. If a card needs separation: one surface step + 1px `--rule` border. No resting blurred shadow, no `rgba(0,0,0,.1)` wide shadow.
- No coloured border-left accent on cards/callouts. No card in card.
- No decorative gradients, glass (`backdrop-filter`), grain, glow. Texture only from real material named in DESIGN.md.

## 7. Focus, states, a11y CSS

```css
:focus-visible { outline: 2px solid var(--focus); outline-offset: 2px; }   /* no transition on focus */
.skip-link { position: absolute; inset-inline-start: var(--space-4); translate: 0 -200%; }
.skip-link:focus-visible { translate: 0 0; }
.visually-hidden { position: absolute !important; width: 1px; height: 1px; margin: -1px; padding: 0;
  overflow: hidden; clip-path: inset(50%); white-space: nowrap; border: 0; }

@media (hover: hover) and (pointer: fine) {
  a:hover { text-decoration-thickness: 2px; }
  .btn:hover { --btn-bg: var(--color-accent-hover); }
}
.btn:active { scale: 0.97; transition: scale var(--dur-press, 120ms) var(--ease-out); }

@media (forced-colors: active) { .btn { border: 1px solid ButtonText; } }
```
- Never `outline: none` without a replacement. Focus ring contrast ≥3:1 against both neighbours.
- Hit area ≥44×44px; enlarge invisibly with padding or a `::after` inset, not by visually bloating icons.
- Links in body text are underlined (`text-underline-offset: 0.15em`). Colour alone never marks a link or status.
- Theme browser details: `::selection`, `accent-color`, `caret-color`, scrollbar colour if dark, native `<select>`.
- Dark surfaces: `color-scheme: dark` and matching `<meta name="theme-color">`.
- Honour `prefers-contrast: more` (stronger borders) and `prefers-reduced-transparency`.

## 8. Reduced motion (CSS floor)

```css
@media (prefers-reduced-motion: no-preference) { html { scroll-behavior: smooth; } }   /* optional; native otherwise */
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
  [data-moment], .btn:active { translate: none !important; scale: none !important; }
}
```
Gentler, not zero: no blanket `animation-duration: 0` reset. Keep opacity/colour transitions ≤150ms under reduce, remove movement, collapse staggers. Per-moment pattern: motion.md.

## 9. Images

- `<picture>` with AVIF → WebP → JPEG, `srcset` 400/800/1200/1600w, honest `sizes`.
- `width` and `height` on every `<img>` (or `aspect-ratio` in CSS). `object-fit: cover` with `object-position` set for the mobile crop focus.
- LCP image: `fetchpriority="high"`, no `loading="lazy"`, real `<img>`. Everything below the fold: `loading="lazy" decoding="async"`.
- No rounded corners or filters on place photos; no scrim unless text contrast needs it. Details: imagery-icons.md.

## 10. Typographic polish

```css
body { font-kerning: normal; text-rendering: optimizeLegibility; -webkit-font-smoothing: antialiased; }
h1, h2, h3 { text-wrap: balance; }
p, li { text-wrap: pretty; hanging-punctuation: first; }
.price, .hours, table, time { font-variant-numeric: tabular-nums; }
abbr.caps { font-variant-caps: all-small-caps; }   /* only if the font has real small caps */
```
- Curly quotes “ ” ‘ ’ and apostrophes ’; ellipsis …; en dash for ranges (9–17 h, 2018–2026); em dash sparingly (max one per paragraph).
- `&nbsp;` between number and unit (18&nbsp;mm, 24&nbsp;uur), after "§", and before a short last word in a headline.
- Body left-aligned, ragged right. Never justify without hyphenation. Centre only short lines.
- Sentence case. No single word in a headline switched to italic/bold/colour. Bold + italic never together. Underline only links.
- No caps/mono micro-labels unless DESIGN.md picks caps for one UI role (then tracked +0.06–0.12em, site-wide for that role only).
- Display tracking −0.01 to −0.03em at 32px+, never tighter than −0.04em.

## 11. Code hygiene

- Never `transition: all`; list properties.
- `will-change` only on the element that animates, never globally.
- No `document.write`, zero console errors, passive scroll/touch listeners.
- Classes describe roles (`.nap`, `.service`, `.cta-band`), not looks (`.blue-box`). Repeated blocks are one component class.
- Keep raw colour values out of everything except `tokens.css` (lint fails >12 raw hex outside `:root`).
