## 1. What it is
"React component library for beautiful landing pages": components, blocks, templates and micro-interactions, copy-paste or installed via shadcn CLI / MCP. Stack: React + Tailwind + Motion; templates are Next.js. Not usable in Bexven's static HTML or Elementor builds.
## 2. How it works
Copy source or CLI/MCP install into a React app.
## 3. Rules
n/a (gallery).
## 4. AI tells / anti-patterns it bans
Bans none. Source of many of the most recognisable 2024–26 "AI landing page" effects: Aurora Background, Background Beams, Lamp Effect, Spotlight, Sparkles, 3D Card tilt, Infinite Moving Cards (testimonial marquee), Bento Grid, Globe, Hero Parallax, Macbook Scroll, Moving Border, Text Generate Effect, Tracing Beam, Wavy Background, Floating Dock — usually on a near-black background with indigo/purple glow.
## 5. Data, assets and scripts it ships
React/TS source, Next.js templates; Motion dependency; MCP installer (do not install).
## 6. Area
motion / components
## 7. Take / skip
Skip entirely as a source; add its named effects to the ban list (dark hero + aurora/spotlight/lamp glow, beams, sparkles, 3D tilt cards, testimonial marquee). If a client brief truly needs depth or motion, design a bespoke effect in plain CSS/JS tied to the brand, not one of these.
